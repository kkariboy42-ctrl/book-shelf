### 판독자 배치 판단 (질문에 대한 답)
- **이미지 2장에만 두 명을 붙인다. 맞다.** CSV(10KB)·XLSX(9명)·메일(txt)은 글자 그대로 기계가 읽으므로 「판독 오류」 자체가 없다 — 여기서 생길 오류는 **해석·정규화 오류**이고, 그건 판독자 둘이 아니라 **정규화 코드 둘**(독립 구현)로 잡는다.
- PDF 는 글자층 = 렌더 일치, 숨은 글자·도형·주석 0 이 함정 단계에서 이미 확인됨(01_함정 상단 표). 추가 판독 불필요. 단 규정 조문은 verifier 가 **원문 PDF 에서 직접** 다시 읽게 해(카드 요약 대신) 해석 공유를 줄인다.
- 이미지 2장 중 **수기장부가 더 위험**(손글씨 숫자 21,500 / 3.5 / 6.0 / 23,500, 취소선 위치). 공지는 인쇄체라 위험 낮지만 숫자 하나(375g vs 600g, 10kg/5kg, 축 20)가 Q2·Q5 를 좌우하므로 같이 붙인다.
