## 1. 지금 확인된 사실과, 아직 모르는 것

**확인된 것** (참가 안내문 + 지난 대회 공개 자료 기준)
- 개인전, 각자 기기와 AI 도구를 쓴다. 지난 대회(2025)는 **AI 도구 사용에 제약이 없었다**.
- 2025 예선 5문제·본선 3문제 원문을 읽고 분석했다(`problems/분석.md`). 문제마다 **"AI 답을 그대로 믿으면 틀리도록" 그럴듯한 오답을 미리 깔아 뒀다.** 정석 풀이: 데이터 → 표 → 코드로 계산 → 원본 대조, 그리고 제출 형식 검사.
  - 입력이 텍스트만이 아니다: 메뉴판 이미지, 그림 속 코드, 유튜브 영상, PDF 숨은 레이어, 서류 PDF 150개, 채점 API.
  - 부정형 복수선택(「옳지 않은 것을 모두」)과 엄격한 답 형식(대문자만, JSON, `Approve`/`Deny`)이 반복된다.
  - 문서 속 **AI 대상 지시문(프롬프트 인젝션)** 을 알아보는지가 두 문제에 걸쳐 나왔다.
  - 실제 데이터·정답은 공개 글에 없다. 석판 문제만 그림이 곧 데이터라 직접 풀어 확인했다.
  - 2025 예선은 **온라인 2시간**이었고(주최 측 후기), 참가자 킬러 문항은 이미지 OCR 이 걸린 **춘식도락**이었다. 2026 예선은 5시간이다.
- 2026 주제: 두 마을(교동마을=농산물, 갯마을=수산물) 관계자와 **대화해서 문제를 발굴** → 데이터 **수집·검증·정제** → 조합 업무를 개선할 **AI 에이전트 구축**.

## 4. 미션별 준비 포인트

### ① 대화로 문제 발굴
- 관계자 말에서 **"누가 · 무엇을 · 얼마나 자주 · 얼마나 오래 · 어디에 기록"** 을 뽑는다. 질문 틀: `toolkit/agent_prompt.md`
- 답변을 바로 표로 옮긴다: 문제 / 빈도 / 소요 시간 / 데이터 위치 / 해결 아이디어
- 같은 질문을 다른 관계자에게 다시 물어 **말이 서로 엇갈리는 지점**을 찾는다 → 그게 대개 출제자가 숨긴 함정

### ② 데이터 수집·검증·정제 (예상 함정)

**2025 문제에서 실제로 나온 함정** (근거: `problems/분석.md`)

| 함정 | 나온 문제 | 체크 방법 |
|---|---|---|
| 예시가 정답 방향을 틀리게 유도 | 석판: 예시는 C, 실제는 파이썬 | 예시를 믿지 말고 후보를 전부 **실행** |
| 미끼 리셋·중간값 | 석판: `r="A"` 로 앞 내용 지움 | 머리로 추적 금지, 실행 결과만 믿기 |
| OCR 한 글자 오류 | 춘식도락: 메뉴판 이미지 → 집계 | 두 모델로 옮겨 `csv_diff.py`, 다른 칸만 원본 확인 |
| 문항마다 다른 범위 조건 | 춘식도락: 중식만/1월만/금요일 석식 없음 | 표 한 장 + 문항별 필터를 코드로 |
| 「정확히 ~로 끝나는」 같은 글자 조건 | 춘식도락 Q1 | 정규식으로 세고 경계 사례(`볶음밥`) 따로 보기 |
| 바깥 지식으로 채운 답 | 영상 팩트: 「영상에서 확인되는」 것만 | 타임코드를 못 대면 버림 (`media_cheatsheet.md`) |
| 눈으로 세는 문제 | 영상: 얼굴 마커 개수 | 프레임 뽑아 직접 확대해서 세기 |
| 정의를 그대로 구현해야 하는 용어 | 전투: 전방=수직이등분선 기준 반평면 | 지문 정의 그대로 코드, 애매하면 두 정의로 계산해 비교 |
| 부정형 복수선택 | 전투 Q4·Q5 「옳지 않은 것」 | 보기마다 참/거짓 표를 먼저 만들고 고르기 |
| 파일명 오타 | 전투: `train_battels.json` | 지문 이름 말고 실제 폴더 목록으로 찾기 |
| 문서 속 AI 대상 지시문 | PDF 스텔스, 인수인계 채점 가드레일 | `pdf_stealth.py`, AI 에게 원문 통째로 판단 맡기지 않기 |
| 여러 위반 중 「가장 낮은 번호」 | 입국 심사 | `rule_engine.py` 번호순·첫 위반에서 멈춤 |
| 기준일이 「오늘」이 아님 | 입국 심사: 2025-11-22 | 기준일을 상수로 고정 |
| 서류 누락 자체가 위반 | 입국 심사: 「7가지 서류」 vs 폴더 5개 | 필수 목록과 실제 파일 대조 |
| 제한된 제출 횟수 | 몽타주: 1분 1회, 같은 해시 무효 | `api_loop.py` 사전 검사·로그 |
| 정보가 시간이 지나며 바뀜 | 인수인계: 장소·시작일·한도 변경 | 사안별 시간순 정렬, 최신값 확정 |
| 암호 걸린 자료 | 인수인계: 생일 4자리 zip | 메일·메모에서 생일 찾기 |
| 답 형식 | 전 문제: 대문자만·JSON·대소문자 | `check_format.py` 로 제출 직전 검사 |

### ③ 에이전트 구축

- 반드시 넣을 것: 근거 표시(어느 데이터에서 나온 숫자인지), "모르면 모른다"고 답하는 규칙, 단위·품목 사전

### ④ 비주얼 (경연이라 중요)
- `village-office/` 를 실제 문제에 맞게 **이름·단계·지표·각본만** 바꿔 쓴다(§5).
- 숫자는 **실제 계산 결과**로 채운다. 화면만 화려하고 숫자가 가짜면 감점 위험.
- 전/후 비교 차트 1개 + 파이프라인 + 등장인물 대화 → "문제를 찾았고, 데이터를 고쳤고, 이렇게 바뀌었다" 서사가 한 화면에 보이게.

## 5. `village-office` 사용법

1. `village-office/index.html` 을 크롬으로 연다. 25초짜리 시연 각본이 자동 재생된다. `Space` = 일시정지.
2. 당일엔 **`data.js` 만 고친다**
   - `people`: 실제 관계자 이름·역할, 배경 그림 위 좌표(`x`,`y` %)
   - `stages`, `kpis`: 단계·지표 이름
   - `SCRIPT`: 시간(t초)마다 누가 무슨 말을 하고 어떤 지표가 오르는지
   - `trend`: 도입 전/후 차트 숫자
3. 실제 에이전트 로그를 실시간으로 흘려 넣으려면 브라우저 콘솔에서:
   ```js
   OFFICE.push({ who: "agent", stage: "validate", text: "중복 3건 제거", kpi: { fixed: 3 }, level: "warn" })
   ```
4. URL 로 보여줘야 하면 폴더째 Netlify Drop / GitHub Pages 에 올린다.
