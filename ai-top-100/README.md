## 1. 지금 확인된 사실과, 아직 모르는 것

**확인된 것** (참가 안내문 + 지난 대회 공개 자료 기준)
- 개인전, 각자 기기와 AI 도구를 쓴다. 지난 대회(2025)는 **AI 도구 사용에 제약이 없었다**.
- 2025 예선 문제 예: 메뉴 데이터 분석, 이상한 코드 해독, 영상 팩트 체크, 시뮬레이션 예측, PDF 속 숨은 텍스트 추적 → **"AI 답을 그대로 믿으면 틀리도록" 함정을 깐 문제**가 많았다.
- 2026 주제: 두 마을(교동마을=농산물, 갯마을=수산물) 관계자와 **대화해서 문제를 발굴** → 데이터 **수집·검증·정제** → 조합 업무를 개선할 **AI 에이전트 구축**.

**아직 모르는 것 — 10/23 메일에서 반드시 확인**
- [ ] 제출물 형식: 정답 입력형인지, 에이전트(URL·파일·프롬프트) 제출형인지, 발표 자료가 있는지
- [ ] **미리 만들어 둔 코드·템플릿(이 폴더 같은 것)을 써도 되는지** ← 가장 중요. 금지라면 `village-office` 는 연습·참고용으로만 쓴다
- [ ] 화면 공유·웹캠·신분 확인 같은 감독 방식이 있는지, 지정 브라우저가 있는지
- [ ] 마을 관계자와의 "대화"가 문제 페이지 안 챗봇인지, 횟수 제한이 있는지
- [ ] 채점 방식(정답 수 / 품질 평가 / 시간 가점)

> 위 항목은 공식 공지를 아직 못 봐서 확실하지 않습니다. 메일 받으면 이 체크리스트부터 갱신하세요.

**AI 도구 (전부 로그인 상태 + 유료 한도 여유 확인)**

## 4. 미션별 준비 포인트

### ① 대화로 문제 발굴
- 관계자 말에서 **"누가 · 무엇을 · 얼마나 자주 · 얼마나 오래 · 어디에 기록"** 을 뽑는다. 질문 틀: `toolkit/agent_prompt.md`
- 답변을 바로 표로 옮긴다: 문제 / 빈도 / 소요 시간 / 데이터 위치 / 해결 아이디어
- 같은 질문을 다른 관계자에게 다시 물어 **말이 서로 엇갈리는 지점**을 찾는다 → 그게 대개 출제자가 숨긴 함정

### ② 데이터 수집·검증·정제 (예상 함정)
| 함정 | 체크 방법 |
|---|---|
| 단위 혼용 (관·상자·근·kg·마리·짝) | 환산표를 먼저 확정하고 kg/개로 통일 |
| 품목명 표기 흔들림 (고등어(대), 고딩어, 사과-부사) | 표준 품목 사전 만들고 매핑 |
| 중복 거래 | (날짜, 품목, 수량, 금액) 기준 중복 제거, 의심 건 목록 남기기 |
| 단가 이상치 | 품목별 중앙값 대비 ±3배, 0원/음수 |
| 날짜 형식 혼용 | 10/3, 2026.10.03, 10월 3일 → ISO |
| 출처 신뢰도 차이 | 관계자 말 vs 장부 vs 공시가 — 어느 쪽을 믿을지 근거 기록 |
| 문서 속 숨은 글자 | PDF 텍스트 전체 추출, 흰 글씨·작은 글씨 확인 |
| AI 환각 | 숫자는 **반드시 코드로 재계산**, 모델 2개 교차검증 |

### ③ 에이전트 구축
- 형태 후보(규칙 확인 후 결정): 프롬프트 기반 챗봇 / 도구 호출 에이전트 / 자동 리포트 생성기
- 조합 업무 후보: **수매·출하 정산 자동화**, 위판(경매) 시세 기록·알림, 재고·신선도 경보, 제철 출하 예측, 직거래 주문 응대
- 반드시 넣을 것: 근거 표시(어느 데이터에서 나온 숫자인지), "모르면 모른다"고 답하는 규칙, 단위·품목 사전

### ④ 비주얼 (경연이라 중요)
- `village-office/` 를 실제 문제에 맞게 **이름·단계·지표·각본만** 바꿔 쓴다(§5).
- 숫자는 **실제 계산 결과**로 채운다. 화면만 화려하고 숫자가 가짜면 감점 위험.
- 전/후 비교 차트 1개 + 파이프라인 + 등장인물 대화 → "문제를 찾았고, 데이터를 고쳤고, 이렇게 바뀌었다" 서사가 한 화면에 보이게.

## 5. `village-office` 사용법

1. `village-office/index.html` 을 크롬으로 연다. 25초짜리 시연 각본이 자동 재생된다. `Space` = 일시정지.
2. 당일엔 **`data.js` 만 고친다**
   - `people`: 실제 관계자 이름·역할, 배경 그림 위 좌표(`x`,`y` %)
   - `stages`, `kpis`: 단계·지표 이름
   - `SCRIPT`: 시간(t초)마다 누가 무슨 말을 하고 어떤 지표가 오르는지
   - `trend`: 도입 전/후 차트 숫자
3. 실제 에이전트 로그를 실시간으로 흘려 넣으려면 브라우저 콘솔에서:
   ```js
   OFFICE.push({ who: "agent", stage: "validate", text: "중복 3건 제거", kpi: { fixed: 3 }, level: "warn" })
   ```
4. URL 로 보여줘야 하면 폴더째 Netlify Drop / GitHub Pages 에 올린다.
