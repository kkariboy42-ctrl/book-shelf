# 함정 갈래와 확인 방법 (2025 AI_TOP_100 공개 문제 근거)

원 분석: problems/분석.md. 새 문제에선 이 목록에 없는 함정을 찾는 게 진짜 일이다.

**2025 문제에서 실제로 나온 함정** (근거: `problems/분석.md`)

| 함정 | 나온 문제 | 체크 방법 |
|---|---|---|
| 예시가 정답 방향을 틀리게 유도 | 석판: 예시는 C, 실제는 파이썬 | 예시를 믿지 말고 후보를 전부 **실행** |
| 미끼 리셋·중간값 | 석판: `r="A"` 로 앞 내용 지움 | 머리로 추적 금지, 실행 결과만 믿기 |
| OCR 한 글자 오류 | 춘식도락: 메뉴판 이미지 → 집계 | 두 모델로 옮겨 `csv_diff.py`, 다른 칸만 원본 확인 |
| 문항마다 다른 범위 조건 | 춘식도락: 중식만/1월만/금요일 석식 없음 | 표 한 장 + 문항별 필터를 코드로 |
| 「정확히 ~로 끝나는」 같은 글자 조건 | 춘식도락 Q1 | 정규식으로 세고 경계 사례(`볶음밥`) 따로 보기 |
| 바깥 지식으로 채운 답 | 영상 팩트: 「영상에서 확인되는」 것만 | 타임코드를 못 대면 버림 (`media_cheatsheet.md`) |
| 눈으로 세는 문제 | 영상: 얼굴 마커 개수 | 프레임 뽑아 직접 확대해서 세기 |
| 정의를 그대로 구현해야 하는 용어 | 전투: 전방=수직이등분선 기준 반평면 | 지문 정의 그대로 코드, 애매하면 두 정의로 계산해 비교 |
| 부정형 복수선택 | 전투 Q4·Q5 「옳지 않은 것」 | 보기마다 참/거짓 표를 먼저 만들고 고르기 |
| 파일명 오타 | 전투: `train_battels.json` | 지문 이름 말고 실제 폴더 목록으로 찾기 |
| 문서 속 AI 대상 지시문 | PDF 스텔스, 인수인계 채점 가드레일 | `pdf_stealth.py`, AI 에게 원문 통째로 판단 맡기지 않기 |
| 여러 위반 중 「가장 낮은 번호」 | 입국 심사 | `rule_engine.py` 번호순·첫 위반에서 멈춤 |
| 기준일이 「오늘」이 아님 | 입국 심사: 2025-11-22 | 기준일을 상수로 고정 |
| 서류 누락 자체가 위반 | 입국 심사: 「7가지 서류」 vs 폴더 5개 | 필수 목록과 실제 파일 대조 |
| 제한된 제출 횟수 | 몽타주: 1분 1회, 같은 해시 무효 | `api_loop.py` 사전 검사·로그 |
| 정보가 시간이 지나며 바뀜 | 인수인계: 장소·시작일·한도 변경 | 사안별 시간순 정렬, 최신값 확정 |
| 암호 걸린 자료 | 인수인계: 생일 4자리 zip | 메일·메모에서 생일 찾기 |
| 답 형식 | 전 문제: 대문자만·JSON·대소문자 | `check_format.py` 로 제출 직전 검사 |
